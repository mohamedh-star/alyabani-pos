# الياباني - نظام إدارة المحل (نسخة سطح المكتب)

تطبيق سطح مكتب حقيقي (Windows) لمحل قطع غيار السيارات، بقاعدة بيانات **SQLite حقيقية** بدل localStorage القديم. البرنامج شغال بالكامل من غير إنترنت.

---

## إيه اللي اتغيّر عن النسخة القديمة (المتصفح)؟

- بياناتك دلوقتي في **ملف قاعدة بيانات حقيقي (`alyabani.db`)** على جهازك، مش جوه المتصفح.
- **مش هتتمسح لو مسحت بيانات المتصفح** — لأنها أصلاً مش هناك.
- **مفيش حد أقصى صغير للمساحة** (كانت localStorage محدودة بحوالي 5-10 ميجا فقط).
- كل تعديل (بيع، شراء، صنف جديد...) بيتحفظ فورًا وتلقائيًا على القرص، من غير ما تعمل حاجة.
- كل الميزات اللي عملناها قبل كده (نقطة البيع، المخزون، العملاء، الموردين، الفواتير، الصلاحيات، الباركود...) شغالة **بنفس الشكل بالظبط** — الفرق بس في مكان تخزين البيانات.

---

## المطلوب على الكمبيوتر بتاعك (مرة واحدة بس)

### 1) تثبيت Rust
افتح المتصفح على: https://rustup.rs
نزّل ونفّذ الملف، واختار الخيار الافتراضي (Enter لكل الأسئلة). لازم يكون عندك أيضًا **Microsoft C++ Build Tools** — لو مش مثبت، rustup هيقولك ويديك لينك مباشر لتثبيته.

بعد التثبيت، افتح **PowerShell أو Command Prompt جديد** وتأكد إنه اتثبت صح:
```
rustc --version
cargo --version
```

### 2) تثبيت Node.js
نزّل من: https://nodejs.org (اختار النسخة LTS) ونفّذ التثبيت العادي (Next, Next, Finish).
تأكد إنه اتثبت:
```
node --version
npm --version
```

## خطوات البناء (تنفذها مرة واحدة، أو كل ما تعمل تعديل في الكود)

1. فك ضغط المجلد `alyabani-pos` في أي مكان على جهازك (مثلاً سطح المكتب).
2. افتح **Command Prompt أو PowerShell** جوه نفس المجلد (تقدر تكتب `cd` وتوديه لمسار المجلد، أو تفتح المجلد وتكتب `cmd` في شريط العنوان في مستكشف الملفات وتدوس Enter).
3. نفّذ الأمر ده أول مرة بس (تثبيت أدوات البناء):
   ```
   npm install
   ```
4. لتجربة البرنامج مباشرة أثناء التطوير (بيفتح نافذة البرنامج فورًا):
   ```
   npm run dev
   ```
5. لعمل **نسخة نهائية مثبتة (.msi أو .exe) تقدر توزعها على أي جهاز**:
   ```
   npm run build
   ```
   بعد ما ينتهي (ممكن ياخد كذا دقيقة أول مرة)، هتلاقي ملف التثبيت جوه:
   ```
   src-tauri\target\release\bundle\msi\
   src-tauri\target\release\bundle\nsis\
   ```
   شغّل ملف الـ `.msi` أو `.exe` زي أي برنامج عادي، وهيتثبت على الجهاز.

## أول تشغيل

- هيظهرلك شاشة تسجيل دخول، الحساب الافتراضي: **اسم المستخدم: admin — كلمة المرور: admin**
- من صفحة الإعدادات تقدر تغيّر كلمة المرور أو تضيف حسابات موظفين.
- مكان ملف قاعدة البيانات نفسه هتلاقيه مكتوب في صفحة الإعدادات (كارت "قاعدة البيانات")، وفي زرار "📂 فتح مكان ملف قاعدة البيانات" في الشريط العلوي يوديك له مباشرة في مستكشف الملفات.

## النسخ الاحتياطي

- زرار "💾 إنشاء نسخة احتياطية الآن" (في الشريط العلوي طول الوقت) بينسخ ملف قاعدة البيانات بالكامل لأي مكان تختاره (فلاشة USB، مجلد تاني، أونلاين درايف لو حابب... إلخ).
- افعل الخطوة دي بانتظام (أسبوعيًا مثلاً) واحتفظ بالنسخة في مكان تاني غير الجهاز نفسه.

## لو عايز تغيّر شعار البرنامج (الأيقونة)

الأيقونة الحالية شكل placeholder بسيط. لو عندك لوجو خاص بالمحل (صورة مربعة PNG بجودة عالية)، نزّل الأداة:
```
npm install -g @tauri-apps/cli
npx tauri icon path\to\your\logo.png
```
هتولّد كل مقاسات الأيقونة المطلوبة تلقائيًا جوه `src-tauri/icons/`.

## أهم ملاحظة

هذا مشروع كود مصدري (source code) — البناء (`npm run build`) لازم يتم **على جهاز Windows فعلي** (أو أي كمبيوتر عادي، مش من الهاتف)، لأن ده طبيعة أي برنامج سطح مكتب حقيقي. بعد ما تبني ملف التثبيت مرة واحدة، تقدر تنسخه وتوزعه على أي جهاز تاني في المحل من غير الحاجة تعيد البناء.
